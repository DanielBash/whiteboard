Тема проекта: Разработка программного обеспечения длярасширение функционала школьной доски Irbis
Актуальность:
Много учеников пишет неразборчиво. Из-за этого остальные ученики могут не понять почерк одноклассника, что может привести к пустой трате времени.
Наш расширенный функционал для электронной доски Irbis разработан для решения таких проблем.
Наша доска будет автоматически корректировать почерк, чтобы ни у кого не возникло проблем прочитать, что написано. 
Таким образом, доска сможет стать умным помощником учителя, который понимает написанное от руки, исправляет и показывает.
Также наша доска сможет мгновенно визуализировать написанное учителем от руки (например, учитель пишет уравнение - система мгновенно строит график и т.п.) и
 воспроизводить голосовые сообщения.
Цель:
Разработать расширенный функционал для электронной доски Irbis, чтобы сделать учебный процесс более удобным и эффективным.
